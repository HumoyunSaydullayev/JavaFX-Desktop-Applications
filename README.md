## 📌 Overview / Loyiha haqida

### English
**JavaFX Desktop Applications & GUI Suite** is a curated collection of desktop applications and interactive graphical interfaces developed with **JavaFX** and **FXML**. The repository showcases core GUI programming concepts, including real-time 2D game loops (Snake Game), dynamic keyframe animations, 2D geometric translations and transformations, rich multimedia integration (`MediaView`, `WebView`, `TabPane`), and interactive database forms.

### O‘zbekcha
**JavaFX Desktop Applications & GUI Suite** — bu **JavaFX** va **FXML** texnologiyalari yordamida yaratilgan desktop dasturlar va interaktiv grafik interfeyslar to'plamidir. Repositoriyda 2D o'yin fizikasi (Klassik Ilon/Snake o'yini), animatsiya va vizual effektlar, 2D geometrik transformatsiyalar, multimedia integratsiyasi (`MediaView`, `WebView`, `TabPane`) hamda ma'lumotlar bazasi bilan ishlovchi ro'yxatdan o'tish shakllari jamlangan.

## 🎮 Included Applications / Dasturlar to‘plami

| Loyiha / Module | Tavsif (Description) | Texnologiyalar |
|---|---|---|
| **🐍 ilon (Snake Game)** | Real-time 2D Snake game with collision detection, score counter, and keyboard controls | JavaFX Canvas, Timeline, Key Events |
| **✨ Animation Suite** | Path transition, fade, rotate, and sequential animations | `Timeline`, `KeyFrame`, `TranslateTransition` |
| **📐 JavaFX Translation** | Interactive geometric rectangle/shape transformations | 2D Transformation Matrices, Event Listeners |

| **🔢 Practical Lab Tasks (2–7)** | Registration forms, calculator interfaces, and database dialogues | FXML, Controllers, CSS Styling |

## 🛠️ Requirements & How to Run

1. **Prerequisites:**
   - JDK 17 or higher
   - JavaFX SDK configured (or running via Maven)
2. **Clone & Open:**
   ```bash
   git clone https://github.com/HumoyunSaydullayev/JavaFX-Desktop-Applications.git
   ```
3. Open any project subfolder (e.g., `ilon` or `Animation`) in **IntelliJ IDEA** or your preferred Java IDE.
4. Run `HelloApplication.java`.
